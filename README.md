# Gdańsk Weekend Radar

Персональная статическая афиша событий Гданьска на ближайшие выходные.

## Что уже есть

- фильтры по дате, бесплатности, solo-friendly и outdoor;
- поиск по названию и месту;
- ссылки на первоисточники;
- ближайшие выходные и подписи календаря вычисляются автоматически по времени Варшавы;
- интерфейс скрывает события, дата или время окончания которых уже прошли по времени Варшавы;
- GitHub Action автоматически запускается каждые 6 часов, удаляет завершившиеся события и собирает события ближайших выходных из открытых источников;
- сборщик сам находит на главной Informator Pomorza статью, даты которой покрывают целевые выходные, и разбирает её по дням; устаревшая статья не используется;
- после каждого расписанного запуска Pages пересобирается и публикуется тем же workflow, даже если `GITHUB_TOKEN`-коммит не запускает другие workflows;
- заголовок периода в данных и календаре формируется автоматически.

## Важно про источники

GitHub Actions не может надёжно читать закрытые Facebook-группы или приватные Telegram-каналы. Для них нужны публичные страницы, RSS или отдельный API-токен. Поэтому автоматический сборщик не обходит авторизацию и не имитирует браузер.

## Публикация

Для первого включения откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. После этого сбор и публикация выполняются автоматически каждые 6 часов; `workflow_dispatch` оставлен для ручной диагностики. Если Informator ещё не выпустил статью на нужные выходные, сборщик продолжает использовать остальные доступные источники и записывает этот статус вместо подстановки прошлой статьи.

## Локальная проверка

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.

Запуск тестов расчёта дат и очистки данных:

```bash
node --test scripts/*.test.mjs
```
